ڕستەی ڕانەبردووی سادە (کردارە نەشازەکان)

چاوگەکان و وێنەکان، تاقیگەی گەردانکردن لە کاتی ئێستادا، و ڕێزمانی ڕەگ

نمرەی تاقیکردنەوە: ۰ / ۹
🖼️ ڕاهێنانی ٦-١: چاوگی گونجاو لە ژێر وێنەی گونجاودا بنووسە
ڕێنمایی: بۆ هەر وێنەیەک، چاوگی گونجاو لە منووەکە هەڵبژێرە.
🔬 تاقیگەی گەردانکردنی کردار لە کاتی ڕانەبردوودا (Dema Niha)
ڕێنمایی: لە لیستی لای ڕاست کردارێک هەڵبژێرە تا گەردانکردنی لەگەڵ جێناوەکان ببینیت.
📖 ڕێزمانی دروستکردنی ڕەگی کردار و کاتی ڕانەبردوو
فۆرموولی کاتی ڕانەبردووی سادە (Dema niha ya sade):
دە + ڕەگی ڕانەبردوو + جێناوی لکاو (دەچم / دەکڕم)

💡 یاسای دۆزینەوەی ڕەگ:

(ن)ی چاوگ و نیشانەی ڕابردوو (ی، ت، و، ا، د) لادەبرێن و ڕەگی کردار دەمێنێتەوە.
نموونە: چوون ➔ چ (دە + چ + م = دەچم / Ez diçim).
